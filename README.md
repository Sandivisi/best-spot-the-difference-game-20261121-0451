**Cari Bedanya — Taman Senja**: game spot-the-difference orisinal yang jalan offline di browser desktop. Dua gambar nyaris identik berdampingan, klik perbedaannya untuk menandai, dan temukan semuanya sebelum waktu habis. Tiga scene yang digambar prosedural di kanvas — Kebun Senja (7 perbedaan), Pantai Pagi (8 perbedaan), dan Hutan Hujan (9 perbedaan) — dengan timer, petunjuk (tombol H), skor, dan efek suara sintetis WebAudio. Tanpa aset luar, tanpa library, tanpa network request.

## Run it

```sh
python3 -m http.server 8080 --directory game
# lalu buka http://localhost:8080 di desktop Chrome
```

Mainkan dengan mouse (klik perbedaan di gambar A atau B) dan keyboard: `H` petunjuk, `R` ulangi level, `1/2/3` pindah level, `Enter` lanjut setelah menang/kalah.
